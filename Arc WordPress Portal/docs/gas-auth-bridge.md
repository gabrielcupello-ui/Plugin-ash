# Authentication bridge between WordPress and Google Apps Script

The **ARC Portal** plugin can authenticate WordPress users against a shared Google Apps Script endpoint and, conversely, issue signed tokens that Apps Script apps can validate.

## Simplest usage mode (Option 1)

Pass the logged-in WordPress user's email as a parameter to each app:

1. In **Settings > ARC Portal**, enable **Pass WordPress email to the apps**.
2. Embedded URLs will look like: `https://script.google.com/.../exec?wp_user=user@ashrivercollective.com`.
3. Modify each app so that, if it receives `wp_user`, it verifies that the email exists in its employee sheet and avoids asking for a manual login.

## Advanced mode (Option 2): SSO with shared endpoint

1. Create a new Apps Script Web App (or add a `doPost` to an existing app).
2. Paste the example code below.
3. Copy the deployment URL into **Settings > ARC Portal > Shared GAS endpoint URL**.
4. Configure the same **API Secret** in WordPress and in the script.

### Actions the GAS endpoint must support

| Action | Input | Expected response |
|--------|-------|-------------------|
| `validate` | `{ action: "validate", email }` | `{ success: true/false, user: { ... } }` |
| `authenticate` | `{ action: "authenticate", email, password }` | `{ success: true/false, user: { ... } }` |
| `sync_user` | `{ action: "sync_user", email, name, role, active }` | `{ success: true }` |

### Example `doPost` in Apps Script

```javascript
function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents || '{}');
    const action = data.action;

    if (action === 'validate') {
      return jsonResponse(validateUser_(data.email));
    }

    if (action === 'authenticate') {
      return jsonResponse(authenticateUser_(data.email, data.password));
    }

    if (action === 'sync_user') {
      return jsonResponse(syncUser_(data));
    }

    if (action === 'verify_token') {
      return jsonResponse(verifyToken_(data.token, data.secret));
    }

    return jsonResponse({ success: false, error: 'Action not supported' });
  } catch (err) {
    return jsonResponse({ success: false, error: err.toString() });
  }
}

function jsonResponse(payload) {
  return ContentService.createTextOutput(JSON.stringify(payload))
    .setMimeType(ContentService.MimeType.JSON);
}

function validateUser_(email) {
  // Replace with your app logic: look up the email in the Employees/Administrators sheet.
  const user = findUserByEmail_(email);
  return { success: !!user, user: user || null };
}

function authenticateUser_(email, password) {
  const user = findUserByEmail_(email);
  if (!user) return { success: false };
  // Validate the password using the hash used in your app.
  const valid = verifyPassword_(password, user.password);
  return { success: valid, user: valid ? user : null };
}

function syncUser_(data) {
  // Update or create the user in your GAS database.
  upsertUser_(data);
  return { success: true };
}

function verifyToken_(token, secret) {
  // Validate a signed token generated by WordPress.
  // Token format: email|expires|userId|hmac
  const parts = String(token || '').split('|');
  if (parts.length !== 3 && parts.length !== 4) return { success: false };
  const [email, expires, userId, hash] = parts.length === 4 ? parts : [parts[0], parts[1], parts[2], ''];
  if (Number(expires) < Date.now() / 1000) return { success: false };
  const payload = email + '|' + expires + '|' + userId;
  const expected = Utilities.computeHmacSignature(Utilities.DigestAlgorithm.SHA_256, payload, secret || 'wp-secret')
    .map(function (b) {
      var h = (b & 0xff).toString(16);
      return h.length === 1 ? '0' + h : h;
    }).join('');
  return { success: hash === expected, email: email, userId: userId };
}
```

## Signed tokens from WordPress

The bridge can generate signed tokens (`Arc_Portal_GAS_Auth_Bridge::generate_token()`). GAS apps can use `verify_token` to trust a session started in WordPress without asking for a password.

## WordPress REST endpoints

- `POST /wp-json/arc-portal/v1/gas-auth/validate` - Validates an email against GAS.
- `POST /wp-json/arc-portal/v1/gas-auth/token` - Generates a signed token (requires login).
